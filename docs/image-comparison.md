# 选图对比

## 使用

在「我的图片」打开「批量管理」，按顺序勾选 2～4 张图片，点击工具栏中的「对比」。图库只保留这一处入口，不再单独显示「继续对比」按钮；对同一组、相同顺序的图片再次进入会恢复上一轮视图。允许不同会话的图片一起比较；原有批量管理 200 张上限、收藏和下载等操作保持原规则。少于 2 张或超过 4 张时，对比按钮禁用并展示原因。

对比进入独立的 `/images/compare` 全屏页面，隐藏工作台导航和原图库。左侧是半透明的浮动缩略图卡片，覆盖在画面上，不占用图片宽度；顶部一行显示「我的图片 已选数/总数」，不显示额外说明。底部居中放两个圆角胶囊：一个包含返回、同步、缩放、画质和纯净查看图标，一个包含当前图片字母、收藏、下载和继续编辑图标。「继续编辑」与收藏、下载使用相同的普通图标按钮背景。窄屏时两张胶囊可上下排列。

后台图库和导航仅隐藏可见性，保留网格列宽、页面高度及虚拟列表的测量结果；不使用 `display: none`，也不将外层页面切成视口高度。对比路由在绘制前锁定滚动并补偿滚动条宽度，退出时同样在绘制前恢复样式和位置，工作台的通用路由滚动恢复跳过此次返回。对比期间暂停后台图库的自动续页和滚动跳转；普通进入／退出不主动刷新图库数据，收藏和不可用图片等真实变化仍按原逻辑同步。

缩放直接复用编辑界面的 `ImageZoomSlider`（相同轨道、滑块及百分比），不再显示左右加减按钮。百分比始终表示当前图片的原图像素比例，100% 与原图 1:1 含义一致；手动调整范围与编辑器一致，为 10%～300%，步长 1%。默认适应视图可根据图片与视窗尺寸低于 10%，手动调整再进入编辑器范围。同步手动缩放时各图使用相同的原图百分比，归一化观察位置继续同步。

「同步查看」开启时使用 `ScanEye` 图标，tips 为「关闭同步查看」；关闭时切换为 `Eye`，tips 为「开启同步查看」，同时保留按钮选中状态。放大和还原共用一个位置：适应状态显示 `Maximize2`，点击进入 100%；调整后显示 `Minimize2`，点击返回适应，tips 与灵感空间预览一致。

对比页所有按钮使用和对话图片工具栏相同的深色圆角气泡 tips，带小箭头和淡入效果；不使用浏览器原生 title 提示。提示采用独立浮层，避开屏幕边界及图库滚动裁切，支持鼠标悬停和键盘聚焦；点击、滚动或拖动主图时隐藏。按钮保留无障碍名称和选中状态。

左侧列表与图库当前搜索／收藏筛选无关，按当前账号全部图片从新到旧分页加载，滚动到底继续加载，可用鼠标滚轮、鼠标拖动或触摸滑动；滚动条隐藏且不保留占位，缩略图居中显示。初始选中的历史图片即使不在第一分页中也会临时置于前部，本轮对比中取消选中后仍保留缩略图供重新选择；对应分页加载后合并去重，候选缓存不跨账号保存。点击缩略图选中，再次点击取消选中；右下角勾选标记仅表示已选，不再是独立按钮，未选图不显示加号。最多 4 张，允许全部取消后重新选择；空选时显示选图提示，相关图片操作禁用。达到上限时先移出一张再选其他图片，不静默替换。

未固定时，图库不显示展开／收起耳朵，初次进入展示约 2 秒后自动隐藏；鼠标移入左侧 12px 透明感应区即展开，移出图库及其边缘过渡区约 300ms 后收起，期间返回会取消隐藏。图库内选图、滚动、按住拖动和键盘操作时保持展开。固定后改为点击耳朵手动展开／收起：展开时仅鼠标移入卡片或耳朵时显示耳朵；收起后默认隐藏耳朵，鼠标靠近左边缘时再显示，点击才展开图库。键盘聚焦耳朵时可见，触屏可轻触左边缘重新展开。展开保留原滚动位置及候选；收起不改变图片画布尺寸，并暂停列表自动续页。

「我的图片」标题前提供 `Pin`／`PinOff` 按钮：选中 `Pin` 后进入固定状态并显示手动控制耳朵，取消固定恢复自动显隐。固定选择和展开／收起状态分别写入当前浏览器的 localStorage，下次进入从首帧直接沿用，不先展开再收起；无记录时默认不固定、先短暂展示再自动隐藏。手动收起不取消固定，自动显隐也会更新展开记录，拖动主图、纯净查看或窗口失焦造成的临时隐藏不覆盖记录。存储不可用时仍可在本轮使用。未固定时，透明边缘入口支持键盘聚焦打开，触摸设备可轻触左边缘展开并在轻触外部后隐藏；固定时键盘或触屏直接操作耳朵。对比缩放条清除通用输入框的左右内边距、边框及焦点外框，避免轨道两端内缩。

底部工具栏的 `Maximize` 图标开启「纯净查看」，持续隐藏图库、边缘入口或耳朵、底部工具栏、图片编号和辅助提示，画布尺寸、缩放和平移保持不变。固定图库同样会在纯净查看和主图拖动期间暂时隐藏，结束后恢复此前手动展开／收起的状态。按 Esc 优先退出纯净查看；鼠标移到屏幕底部可显示 `Minimize` 恢复按钮，触摸设备可轻触底边恢复。恢复入口支持键盘聚焦与相同样式的 tips；拖动期间恢复入口也会隐藏。纯净查看不写入草稿，刷新后恢复普通界面。

私有对话的单图和组图工具栏，在「复制图片」按钮后提供「选图对比」。点击的结果图排为 A 并默认选中，优先加入同组其他结果，再按消息列表顺序补入当前对话可见的其他结果，最多 4 张，按图片 ID 去重。只比较结果图：引用原图、素材、未显示的历史版本和正在生成的空位不入选，也不沿用上轮图库的选中状态。进入后可从左侧图库继续选图；返回按钮回到原对话。共享只读会话不提供此按钮，也不加载查看者私有图库。

「我的图片」平铺和时间轴卡片的悬浮操作栏，在编辑按钮后提供同样的对比图标。点击后以当前图作为 A，并按新到旧补入同一对话的结果图，最多 4 张；不受图库搜索、收藏筛选或已加载分页影响。只在点击时查询该对话最多 4 条图库记录，无所属对话时只带入当前图。读取期间显示加载图标，失败显示提示；离开页面或切换账号时取消请求。返回对比前的图库位置，保留原有批量选择。

图库悬浮操作栏使用原有的独立圆形按钮，居中单行排列，无整体胶囊背景。时间轴、窄卡片和宽平铺卡片均直接显示「编辑、对比、下载、更多」四个按钮。小卡片采用最多 30px 的四列按钮和 3px 间距，极窄时等比缩小圆形按钮以避免换行。更多菜单只包含「加入灵感、加入素材」；下载按钮仍提供原图／预览图／缩略图选项、文件信息和命名规则。菜单通过独立浮层避免图片裁切，打开时工具栏保持显示，支持方向键、Esc、Tab 和点击外部关闭；收藏继续位于右上角。

我的图片、灵感空间和素材库的图标操作统一使用深色圆角气泡 tips，包含收藏、编辑、下载、分享、删除、更多及预览工具。共用 `ActionTooltip` 浮层避免卡片裁切，支持键盘聚焦和屏幕边缘避让；点击、滚动、打开菜单、切换页面时隐藏，替代对应按钮的原生 title。

统一 tips 在捕获阶段监听 `click`：键盘 Enter／空格或辅助技术激活按钮时，同样在按钮动作执行前关闭提示，不依赖鼠标按下或弹窗自动转移焦点；不阻止按钮原有动作。

图片画布覆盖整个视口，左侧图库及上下操作均不为画布留出裁切区域；图片保持原比例，放大后可覆盖各格边缘。左列图片的编号避开图库卡片，其图片本身不缩进。拖动主图或双指操作时隐藏左侧图库及全部对比操作卡片、编号、收藏、画质提示、信息面板和加载／错误操作，松开后恢复。隐藏通过可见性完成，不改变画布尺寸或排列；指针取消、捕获丢失、窗口失焦时也会恢复。拖动图库本身用于滚动列表，不触发隐藏。

图片按勾选顺序编号。桌面根据图片比例和视口大小，选择完整图片显示面积最大的排列：四张竖图优先四列，横图在两行显示更大时采用两行；三张图和两张图同样按实际可用面积选择。手机显示上下两个观察窗，底部操作胶囊列出全部已选图的 A／B／C／D 按钮，将对应图片切入当前观察窗，不改变选中集合。点击观察窗或编号改变当前图片；左侧缩略图继续只负责选中／取消。

- 同步查看默认开启，手动缩放使用相同的原图百分比，平移同步相对位置；关闭后可以独立操作。
- 初始「适应」完整居中显示图片，鼠标呈放大光标。点击图片进入原图 100%，水平居中并从图片顶部查看，与编辑器一致；再次点击或点击同位置的还原按钮恢复适应。
- 调整过的视图使用抓手光标；按住拖动可平移。点击和拖动采用编辑器相同的 4px 阈值，拖动、双指手势、指针取消和捕获丢失均不触发点击缩放。空白留边点击不缩放。
- 进入对比默认加载原图，仍按适应视窗比例显示，最多同时下载／解码两张。加载期间使用预览占位，原图就绪后替换且保持当前缩放和平移；用户仍可手动切换为预览图。只在原图加载中或失败需重试时显示提示，不常驻显示「当前为预览图」或「原图已就绪」。
- 图片类型按钮的预览状态使用 `ImageMinus`，原图状态使用 `Image`；tips 表明下一步「切换为原图／预览图」，点击后通过居中 toast 直接提示「已切换为原图／预览图」，不使用「模式」措辞。显式选择预览后，放大操作不会自动覆盖此选择。
- 图片类型和视图状态独立：切换只替换显示资源，保留当前缩放、观察中心、选中图片及布局，不调用适应重置。已经读取的原始尺寸在切回预览后继续用于几何计算。
- 每张图片顶部显示当前资源的「原图／预览图」、尺寸和文件大小，悬停信息卡同步展示。原图优先使用实际解码尺寸和下载 Blob 字节数，预览图使用实际解码尺寸及已有下载规格接口返回的字节数（与下载菜单共用缓存）；元数据尚不可用时不拿原图大小冒充预览图大小。原图加载期间若仍显示预览，占位信息也保持为预览。最长边不超过 1600px 的图片压缩为 WebP 后可能尺寸相同、文件大小不同；画布几何计算继续使用原始尺寸，不随文件类型变化。
- 鼠标移入每张图片顶部的编号／尺寸区域，直接显示该图的信息卡，包含提示词、尺寸、文件大小、类型、时间及复制提示词按钮，不再显示原 tips，也不改变当前选中图。卡片跟随触发区域定位并避开屏幕边界，可移入卡片阅读、滚动或复制；离开后延迟关闭。键盘聚焦或触屏点击同样可以打开。Tab 从尺寸按钮直接进入卡片，Shift+Tab 从首个按钮返回；末尾 Tab 关闭卡片并继续到图片收藏按钮，键盘焦点停留在卡片内时不自动关闭。Esc 或关闭按钮会关闭并恢复触发按钮焦点，点击外部直接收起。底部工具栏不再保留信息图标。
- 每格独立收藏。下载和继续编辑作用于底部标明的当前图片。
- 继续编辑沿用现有编辑器请求，只携带这轮仍有效的图片；打开编辑器不会自动生成。
- 返回选图保留底层图库滚动和批量勾选。取消收藏的图片仍保留在当前对比中。
- 点击画面或图片编号时，左侧会自动滚动到对应缩略图；当前缩略图已完整可见时不额外移动。再次点击同一张图也可重新定位；折叠或拖动期间推迟定位，在展开／松手后执行，滚轮平移不会逐帧触发定位。

键盘支持 1～4 选择图片、F 切换收藏、0 适应、+／−缩放。输入框、文字选区、输入法组合输入及带 Ctrl／Meta／Alt 的组合键不会被抢占。Esc 优先退出纯净查看，再关闭下载菜单或信息面板，最后返回图库；不清空原批量选择。浏览器返回同样保留草稿；刷新对比页会直接恢复这一轮，包括空选状态。

## 草稿和权限

当前标签页保留一轮草稿，刷新对比页可直接恢复；返回图库后从批量工具栏再次对比相同图片也可继续。退出或切换账号会清除草稿。浏览器 storage 不可用时退回内存。

sessionStorage 的 `gpt-image.image-comparison.v1` 存放账号 ID、图片 ID 顺序、当前 ID、同步开关和视图参数，读取时严格校验账号、版本和参数范围。不保存提示词、媒体 URL、图片文件或凭据。收藏使用原有服务端数据，长期保存。

成员详情按 ID 单独读取并使用包含账号 ID 的 Query key。成员不依赖图库已加载的页，不跟随收藏筛选或图库排序变化。不可访问的图片统一显示不可用，其他图片可继续查看；仍有至少两张时可移除不可用项。网络失败可以单格重试。

## 实现

- `src/lib/imageCompare.ts`：坐标、尺度、草稿校验、0～4 张候选增删、对话默认选图、手机观察窗切换和按完整图面积选择排列。
- `src/hooks/useImageCompareViewport.ts`：全屏页内的视图状态，requestAnimationFrame 合并交互更新。
- `src/hooks/useCompareOriginals.ts`：有界原图下载和解码，取消请求、释放对象 URL。
- `src/store/imageCompare.ts`：账号隔离的临时草稿；App 认证状态变化时绑定或清理。
- `src/components/images/ImageCompareWorkspace.tsx`：全屏画布、悬浮操作栏、详情和操作。
- `src/components/images/ImageCompareTooltip.tsx`：对比页统一委托式 tips，匹配聊天图片工具栏样式，提示通过 portal 避免图库裁切。
- `src/components/images/ImageCompareInfoCard.tsx`：由每张图片顶部尺寸区域触发的信息卡，按触发图片读取内容，保持独立于当前选中图。
- `src/components/images/ImageCompareLibrary.tsx`：左侧全部图片、游标分页、虚拟化和鼠标拖动滚动，选图保持独立于已加载分页。
- `src/components/chat/ImageCompareButton.tsx`：单图／组图共用入口；`ChatMessages.tsx` 的显式 `compareImage` 能力在共享模式强制关闭。
- `src/components/images/ImageCompareViewport.tsx`：单格显示、滚轮和双指／拖动手势。
- `src/components/ImageDownloadMenu.tsx`：可选 portalContainer，使既有下载菜单位于对比页内；其他调用方默认仍挂载 document.body。
- `src/components/WorkbenchShell.tsx`：`/images/*` 共用图库组件；对比路径隐藏导航并跳过页面切换位移动画。图库状态保留，返回后恢复滚动。
- `src/i18n/messages/imageCompareMessages.ts`：11 种语言文案和帮助文章。

API 复用 `GET /api/images/:imageId`、`PUT /api/images/:imageId/favorite` 和既有下载接口，无数据库变更，无 Provider／生图路由配置变更。

收藏成功后更新当前对比、图片详情和图库卡片缓存，并刷新收藏统计；退出对比后重新校准图库分页。图片详情和原图请求不会随拖动每帧重复发出。只有手势结束、选择变化或关闭时保存草稿。
