# 页面加载动效提案

本目录保留三版设计稿。最终实现采用静态 Logo 和简洁加载文字；以下动效方案及推荐标记仅为原始提案记录。设计稿使用仓库现有的 `public/image/logo.png` 绘制，没有更换 Logo。

| 方案 | 动效 | 适用感受 |
| --- | --- | --- |
| A 极简呼吸 | Logo 缩放 96%–104%，透明度 76%–100%，2.4 秒循环 | 安静、轻量 |
| B 柔光呼吸（推荐） | A 的节奏配合淡蓝、淡粉、浅金柔光 | 温和，品牌辨识更强 |
| C 笔迹流光 | Logo 轻微悬浮，下方彩色笔迹 2.8 秒循环 | 更有创作氛围 |

## 建议交互

- 沿用现有登录状态请求，加载结束后立即进入页面，不等待动画播完。
- 只在真正等待时呈现，不设置最短强制停留时间。
- 支持深色主题和 `prefers-reduced-motion`，减少动态效果时显示静态 Logo。
- 使用不定进度的循环动画，不显示虚构进度百分比。
- 长时间等待时补充真实状态或重试入口，不用循环动画掩盖请求失败。
- 实现时复用现有品牌配置；本提案展示的是仓库内置 Logo。

`loading-concepts.png` 为方案对比图。`render_board.py` 使用 Pillow 绘图并复用原始 Logo；没有调用 AI 图像生成接口。

## 当前实现：静态 Logo

- `src/components/PageLoading.tsx` 复用 `ProjectLogo`，沿用现有品牌配置、请求缓存与默认 Logo 回退。
- 用于工作台登录状态检查、登录后 OAuth 跳转等待，以及配置入口加载；保留各入口原有国际化提示。
- Logo 容器为 108px，静态显示，无缩放、透明度或其他循环动画。
- 加载文字使用中文无衬线字体、14px 字号、500 字重和轻微字距，沿用主题的中性灰，与 Logo 间距为 16px。
- 状态提示使用 `role="status"`，保留原有国际化文案。
- 原有请求和路由完成条件不变，不增加延时或最短显示时长。
