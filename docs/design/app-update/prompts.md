# 马良生成提示词

## 角色定稿

为“神笔马良 GPT Image Workbench”的网页版本更新提醒设计一个可用于连续动画的角色定稿：单个 Q 版中国古代小画师“小马良”，约 8 岁男孩，聪明温暖、略带俏皮，黑色头发梳成整洁小发髻，米白色交领汉服，青绿色腰封、发带和飘带，少量鎏金滚边，脚穿软靴；手持一支比手臂略长的黑色笔杆、金色笔箍、白色柔软笔锋的神笔。角色采用精致高端的 3D 国风绘本质感，柔和圆润造型，细腻布料与木质金属细节，色彩以宣纸米色、青绿、鎏金为主，只允许少量蓝粉墨迹光点作为品牌点缀。三分之四正面站姿，神情友好自信，完整全身，角色居中，四周留足透明空间，轮廓清晰，适合缩小到网页右下角 96px 仍可识别。透明背景，不要文字、卡片、卷轴、场景、边框、地面投影或多角色。

## 动作帧公共约束

严格保持角色定稿中的身份、脸型、五官、发髻、服装、神笔、身材比例、材质和色彩，只改变动作与表情。单个完整全身角色，统一镜头距离和脚底基线，透明背景，不生成文字、卡片、卷轴、场景、边框、地面投影或额外人物。

## 六帧动作

1. 从画面右侧俏皮探身，一手拿神笔挥手，友好微笑。
2. 发现右侧有新版本，眼睛一亮，身体转向右侧，神笔顺势抬起。
3. 面向右侧，双手抓住不可见的竖直卡片边缘，神笔斜背在身后，下蹲准备发力。
4. 双脚踩稳、身体向左后仰，双手在右侧用力拉动，衣袖和飘带向右运动。
5. 向左后退一步继续拉动，表情从用力转为开心，衣摆和飘带保留运动感。
6. 收笔站稳、面向观众微笑，一手持神笔，另一手指向右侧，笔尖带少量蓝粉墨迹星光。

第 4、5 帧完成后又以高输入保真补回了斜背的黑金白毫神笔，其他姿态保持不变。

## 待机静态挥手

默认待机使用第 1 帧的静态挥手姿势：五指张开、手掌朝向用户，表情友好，不伸出单独食指或形成指向姿势。鼠标移入时由 CSS 对整张角色图做轻微放大和上抬提示；点击后才进入六帧拉卡片动画。
